# Third-party content

Kuki's source code is released under the MIT License (see `LICENSE`).

Kuki can import lecture material published by third parties. That material is
**not** part of this repository. It is downloaded on the user's request, stored
only on their computer, and keeps its original license:

| Publisher | Courses | License | License page |
|---|---|---|---|
| Harvard University (CS50) | CS50x, CS50 AI | CC BY-NC-SA 4.0 | https://cs50.harvard.edu/x/license/ |
| Yale University (Open Yale Courses) | PHIL 181, ECON 252 | CC BY-NC-SA 3.0 | https://oyc.yale.edu/terms |

Open Yale Courses notes that some third-party content within lectures is not
covered by its Creative Commons license; see each lecture's credits.

Neither Harvard nor Yale endorses Kuki.

The demo deck `samples/search-algorithms.pptx` was written for this project and
is covered by the MIT License. Fonts (Bricolage Grotesque, Atkinson
Hyperlegible) are used under the SIL Open Font License via Fontsource.
