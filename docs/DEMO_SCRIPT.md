# Demo video script (about 3 minutes)

Record with a **real** model running (`ollama pull llama3.2:3b`), not the
development mock. Use `samples/search-algorithms.pptx` so no one else's slides
appear on screen.

| Time | Show | Say |
|---|---|---|
| 0:00 | Wi-Fi off, Kuki library | "This is Kuki, a private AI study buddy. My Wi-Fi is off; everything you'll see runs on this laptop." |
| 0:15 | Drop the sample deck | "I drop in this week's lecture. Kuki reads the slides and the speaker notes." |
| 0:30 | Study pack → Make study pack | "In under a minute I get key concepts, main points, examples and common mistakes." |
| 0:55 | Click a citation chip | "Every line is stitched to where it came from. I can check Kuki instead of trusting it." |
| 1:10 | Quiz me → answer "DFS finds the shortest path because it uses a queue" | "Instead of multiple choice, I explain in my own words. I'll make a classic mistake." |
| 1:30 | Feedback: snag + nudge | "Kuki doesn't just mark it wrong. It found that I mixed up BFS and DFS, and asks a question that makes me fix it myself." |
| 1:50 | Retry → correct | "Second try, I've got it." |
| 2:00 | Weak spots | "Every answer feeds a map of what I keep getting wrong, and my most common kind of mistake." |
| 2:15 | Flashcards → review with keys | "Flashcards are scheduled with spaced repetition and export to Anki." |
| 2:30 | Wi-Fi on → Open courses → import Yale lecture → recording | "And I can import free lectures from Harvard and Yale, credited to their authors, and save the recording for the bus ride." |
| 2:50 | Status checklist | "No account, no API bill, and nothing leaves my computer. That's Kuki." |
